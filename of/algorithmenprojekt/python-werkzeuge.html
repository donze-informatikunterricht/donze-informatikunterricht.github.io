Mit Animationen erkunden: Einfügen, Entfernen, append und pop

Erlaubt sind

Klappen Sie einen Eintrag auf, um Erklärung und Beispiel zu sehen.

liste[position] – Werte lesen und überschreiben

Die Positionen beginnen bei 0. Mit einer Zuweisung ersetzen Sie ein vorhandenes Element.

liste = [4, 3, 2]
wert = liste[1]  # 3
liste[1] = 7
# liste: [4, 7, 2]
liste[start:ende] – Teilbereiche verwenden (Slicing)

Sie dürfen Teilbereiche einer Liste verwenden. Der Bereich beginnt bei Position start und endet vor Position ende. Das Ergebnis ist eine neue Liste; die ursprüngliche Liste bleibt unverändert.

liste = [4, 7, 2, 8, 5]

teilbereich = liste[1:4]  # [7, 2, 8] – Positionen 1, 2 und 3
anfang = liste[:3]       # [4, 7, 2] – vom Anfang bis vor Position 3
rest = liste[2:]         # [2, 8, 5] – ab Position 2 bis zum Ende
kopie = liste[:]         # [4, 7, 2, 8, 5] – die ganze Liste kopieren

Die Positionen im neuen Teilbereich beginnen wieder bei 0. Enthält der gewählte Bereich keine Elemente, erhalten Sie eine leere Liste. Beim Erstellen eines Teilbereichs werden die enthaltenen Elemente in eine neue Liste übernommen; auch das verursacht Arbeit.

len(liste) – Anzahl der Elemente

Die letzte gültige Position einer nicht leeren Liste ist len(liste) - 1.

liste = [4, 3, 2]
anzahl = len(liste)  # 3
Werte tauschen – mit einer Hilfsvariablen

Speichern Sie einen Wert zwischen, damit er beim Überschreiben seiner Position nicht verloren geht.

liste = [4, 3, 2]

hilfsvariable = liste[0]
liste[0] = liste[1]
liste[1] = hilfsvariable

print(liste)  # [3, 4, 2]

Für zwei beliebige Positionen:

hilfsvariable = liste[position_a]
liste[position_a] = liste[position_b]
liste[position_b] = hilfsvariable
liste.pop() / liste.pop(position) – Element entfernen

pop entfernt das Element an einer Position und gibt seinen Wert zurück. Ohne Positionsangabe entfernt es das letzte Element. Jedes Beispiel beginnt mit einer neuen Liste.

Hinten

liste = [4, 3, 2]
entferntes_element = liste.pop()
# liste: [4, 3]    entferntes_element: 2

Vorne

liste = [4, 3, 2]
entferntes_element = liste.pop(0)
# liste: [3, 2]    entferntes_element: 4

An einer bestimmten Position

liste = [4, 3, 2]
position = 1
entferntes_element = liste.pop(position)
# liste: [4, 2]    entferntes_element: 3

Die Liste muss an dieser Position ein Element enthalten. Die erste Position ist 0, die letzte len(liste) - 1. Nach dem Entfernen rücken die folgenden Elemente um eine Position nach links. Entfernen am Listenende braucht dieses Nachrücken nicht; Entfernen vorne oder in der Mitte verursacht zusätzliche Arbeit.

liste.append(wert) – hinten anhängen

Hinten anhängen

liste = [4, 3, 2]
liste.append(7)
# liste: [4, 3, 2, 7]
liste.insert(position, wert) – vorne oder an einer Position einfügen

Vorne einfügen

liste = [4, 3, 2]
liste.insert(0, 7)
# liste: [7, 4, 3, 2]

An einer bestimmten Position einfügen

liste = [4, 3, 2]
position = 1
liste.insert(position, 7)
# liste: [4, 7, 3, 2]

Möglichst hinten anhängen: Verwenden Sie append, wenn der Algorithmus damit denselben Ablauf umsetzen kann. Bei insert müssen die Elemente ab der Einfügeposition nach rechts rücken; bei append müssen bestehende Elemente nicht verschoben werden. Diese zusätzliche Arbeit ist nicht dasselbe wie die Anzahl Ihrer Wertvergleiche.

insert(position, wert) fügt den Wert vor dem bisherigen Element an dieser Position ein. Dieses Element und alle folgenden rücken nach rechts. Anders als liste[position] = wert überschreibt insert keinen vorhandenen Wert.

for- und while-Schleifen – Werte selbst durchlaufen

Das in einer for-Schleife ist erlaubt. Es gehört zur Schleifenschreibweise und prüft nicht, ob ein bestimmter Wert in einer Liste vorkommt.

for position in range(len(liste)):
    print(liste[position])
zusatz.liste_erstellen(anzahl, anordnung) – Testlisten erstellen

Das bereitgestellte Modul erzeugt bei jedem Aufruf eine neue Liste. Für faire Vergleiche erzeugen Sie eine Ausgangsliste einmal und verwenden je Variante eine Kopie mit ausgangsliste[:].

import zusatz

liste = zusatz.liste_erstellen(100, "aufsteigend")
liste = zusatz.liste_erstellen(100, "absteigend")
liste = zusatz.liste_erstellen(100, "zufaellig")
liste = zusatz.liste_erstellen(100, "wiederholend")

Aufsteigende, absteigende und zufällige Listen enthalten die Werte 0 bis anzahl - 1. Wiederholende Listen mischen die Werte 0 bis 4 mehrfach. Listen mit anzahl=0 sind leer.

Die bereitgestellte Funktion ist erlaubt. Die Such-, Sortier- und Umwandlungsschritte entwickeln Sie selbst.

Beispiel für zwei vergleichbare Messungen:

ausgangsliste = zusatz.liste_erstellen(100, "zufaellig")

liste = ausgangsliste[:]
# Erste Variante mit liste messen.

liste = ausgangsliste[:]
# Zweite Variante mit liste messen.

# Zahlensysteme: zwei gleich lange Listen mit gemeinsamer Position
zusatz.stellen_darstellen(

Bei der binären Suche kennzeichnet suchbereich=True den Bereich auch dann, wenn er leer geworden ist. Ausgeschlossene Werte erscheinen grau, die aktuelle Mitte hellblau und ein Treffer rot.

zusatz.ziffernliste_erstellen(darstellung) – Referenzen für Zahlensystemtests

Dieser vorgegebene Testbaustein entfernt das Präfix einer bin()- oder hex()-Ausgabe und liefert eine Liste ganzer Zahlen. Verwenden Sie ihn nur in Testfunktionen.

zusatz.ziffernliste_erstellen(bin(11))  # [1, 0, 1, 1]
zusatz.ziffernliste_erstellen("0b1011") # [1, 0, 1, 1]
zusatz.ziffernliste_erstellen(hex(31))  # [1, 15]

Bei Basis 16 stehen die Werte 10 bis 15 für a bis f. Verbindlich sind beide Richtungen mit Basis 2; weitere Basen 3–9 sind freiwillig.

Nicht erlaubt sind

Erlaubte Referenzen nur in Testfunktionen:

  • Sortieren: sort() auf einer separaten Kopie der Eingabe.
  • Suchen: index() als Referenz für einen vorhandenen Wert. Es liefert das erste Vorkommen und wirft bei fehlendem Wert einen ValueError; den Fall «fehlt» testen Sie mit der Erwartung -1.
  • Zahlensysteme: bin() und hex() zum Überprüfen. Sie liefern Text mit dem Präfix 0b bzw. 0x, keine Ziffernliste. hex() bezieht sich auf Basis 16; verbindlich sind beide Richtungen mit Basis 2; weitere Basen 3–9 sind freiwillig.

Kleine erwartete Ergebnisse bestimmen Sie zuerst selbst. Diese Referenzfunktionen dürfen den selbst entwickelten Algorithmus nicht ersetzen. In der Algorithmusfunktion bleiben sort(), sorted(), index(), bin() und hex() verboten.

  • liste.sort() – die Liste fertig sortieren lassen.
  • sorted(liste) – eine fertig sortierte Liste erzeugen lassen.
  • liste.index(wert) – die Fundposition suchen lassen.
  • bin(zahl) und hex(zahl) – die Umwandlung in der Algorithmusfunktion fertig ausführen lassen.
  • wert in liste und wert not in liste – die Mitgliedschaft prüfen lassen.
  • Tupelzuweisung zum Tauschen, etwa a, b = b, a. Verwenden Sie eine Hilfsvariable.

Die Vergleiche und die Schritte Ihres Algorithmus setzen Sie selbst um.
